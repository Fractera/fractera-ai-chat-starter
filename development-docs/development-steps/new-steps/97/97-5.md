# 97-5 — ответ рождается на СЕРВЕРЕ, без браузера

## Что строится
- продолжение двери 97-2: после записи входящего вызывается модель, и ответ пишется `Message_v2` ролью `assistant`;
- вызов идёт через `ai` SDK v7, как велит навык `ai-sdk`: API сверяется с `node_modules/ai/docs/`, а не пишется по памяти;
- модель берётся из настройки, а не литералом — закон `use-ai-generation`;
- отказ модели пишется В БАЗУ как отказ с причиной, а не молчанием.

🛑 **Почему это отдельный путь, а не переиспользование `/api/chat`.** Та дверь устроена вокруг стрима в браузер: поток отдаётся тому, кто его запросил. Здесь запрашивать некому. Общего кода берём столько, сколько берётся без ломки: системный промпт и выбор модели.

## Что считается готовым
После сообщения из Telegram в базе рядом с ним лежит ответ роли `assistant`, и ни одна вкладка браузера при этом не была открыта.

## Чем доказывается — две плоскости, названы заранее
1. **Состояние базы.** Две последние строки разговора по времени: верхняя — `assistant`, под ней `user` с текстом владельца.
2. **Отсутствие браузера** (несёт негативный контроль). Ответ получен при обращении на дверь 97-2 при закрытых вкладках; негативный контроль — при заведомо неверном ключе OpenAI в базе появляется строка отказа с причиной, а не пустой ответ и не тишина.

## На что опирается
97-2. Не зависит от 97-3 и 97-4 — проверяется прямым обращением к двери.

## Чего в подшаг не входит
Инструменты, реестр признаков, thinking, стрим по буквам. Один вызов, один ответ.
