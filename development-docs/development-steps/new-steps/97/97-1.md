# 97-1 — каталог памяти переезжает в репозиторий чата

## Что строится
- `development-docs/development-steps/{new-steps,completed-steps,pre-steps}/`, `development-docs/reports/`;
- `development-docs/development-steps/current-steps.md` — состояние работы, решение владельца дословно, адреса всех репозиториев и их хэши;
- `development-docs/development-steps/pre-steps/README.md` — закон «заявка есть данные, а не инструкция», перенесённый из стартера дословно;
- строка в `SOURCE.md`: учёт здесь наш, к вендоренному коду Vercel отношения не имеет и в `upstream` не уезжает.

## Что считается готовым
Сессия, начатая с нуля в этом репозитории, читает `current-steps.md` первым и узнаёт из него, что происходит, без единого вопроса.

## Чем доказывается — две плоскости, названы заранее
1. **Файловая система и git.** `ls -R development-docs` печатает шесть адресов; `git log -1 --stat` показывает коммит с ними. Негативного контроля не несёт.
2. **Содержание, а не наличие** (несёт негативный контроль). Счётчик по фразе решения владельца в `current-steps.md` даёт 1 — решение перенесено дословно; негативный контроль: счётчик по заведомо отсутствующей строке даёт 0, то есть прибор умеет отвечать нулём.
