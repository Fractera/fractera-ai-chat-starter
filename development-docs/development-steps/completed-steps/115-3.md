# Шаг 115-3 — Сторож лимита подписки. РАБОТАЕТ 2026-09-05

Канал шага 115 замолчал в 2:32 ночи, и владелец узнал об этом только по тишине. Теперь при
исчерпании квоты в Telegram приходит **точное время сброса**, а по будильнику — **«лимиты
сброшены»**. Без искусственного интеллекта: разбор JSON, таймер, HTTP.

## Что оказалось причиной молчания — и это не поломка

В журнале канала дословно: `You've hit your session limit · resets 3:30am (Europe/Berlin)`.
Время совпало с минутой, когда лёг и локальный Claude Code владельца.

🔒 **ОДИН КОЛОДЕЦ НА ДВОИХ.** Серверный канал работает по подписке владельца, а не по ключу API.
Значит тяжёлая работа за компьютером **вычитается из той же квоты**, что и ответы бота с телефона.
Вчера это построили, но не назвали. Названо теперь.

## Источник данных — не экран, а журнал сессии

✗ **Разбирать ANSI-лог pm2 нельзя.** Полноэкранный интерфейс перерисовывает экран, и фраза в логе
разорвана управляющими последовательностями: `You've[13Ghit[17Gyour[22Gsession[30Glimit`. Наивный
`grep` по фразе не найдёт ничего.

✅ Claude Code сам пишет машинно-читаемую строку в `/root/.claude/projects/-opt-fractera-agent-workspace/<sid>.jsonl`:

```json
"error":"rate_limit","isApiErrorMessage":true,"apiErrorStatus":429,
"quotaLimits":{"status":"rejected","resetsAt":1788571800,"rateLimitType":"five_hour",
               "overageStatus":"rejected","overageDisabledReason":"out_of_credits"}
```

`resetsAt` — точная секунда. Будильник ставится по числу, а не по разбору слов.

## Устройство

| Часть | Где |
|---|---|
| процесс | pm2 `fractera-limit-watch` (десятый) → `/opt/fractera/limit-watch.js` |
| состояние | `/opt/fractera/limit-watch-state.json` (смещения, объявленный `resetsAt`) |
| доступы | токен из `channels/telegram/.env`, адресаты из `access.json → allowFrom` |
| опрос | каталог журналов раз в 5 с, по смещениям |

## Решения, каждое с доводом

🔒 **ТОЛЬКО `sendMessage`, НИКОГДА `getUpdates`.** Telegram отдаёт каждое обновление ровно одному
читателю. Один вызов `getUpdates` отсюда — и переписка владельца начнёт **молча** делиться пополам
между плагином каналов и сторожем. Это та же поломка, от которой в шаге 115 закрывали вкладку
браузера. Запрет стоит комментарием в самом файле, а не только в голове автора.

🔒 **ПЕРВЫЙ ЗАПУСК НЕ ПЕРЕИГРЫВАЕТ ПРОШЛОЕ.** Смещения ставятся на текущий конец файлов, плюс
запись старше 30 минут отбрасывается. Иначе сторож в первую же секунду объявил бы ночной лимит.
✅ негативный контроль снят: `grep -c отправлено` в логе живого процесса = **0**.

🔒 **ЗАВИСИМОСТЕЙ НЕТ.** `node:https` вместо `fetch` (работает на любой версии Node), время
форматируется вручную вместо `toLocaleString` — сборка Node может быть без полной ICU, и `ru-RU`
молча выродится в `C`.

🔒 **ДОСТАВКА ЧЕРЕЗ base64 СО СВЕРКОЙ SHA256.** Файл содержит кириллицу и кавычки; путь
git-bash → WSL → ssh их портит. Base64 — чистый ASCII, иммунитет к перекодировкам.
✅ `9cd085ae…da655` совпало побайтно на обеих сторонах.

🛑 **ВТОРОЕ СООБЩЕНИЕ — ТАЙМЕР, А НЕ ПРОБА.** Пробный запрос стоил бы квоты и требовал влезть в
чужую сессию. Опора — обещание сервера (`resetsAt`). Конструкция самоисправляется: если сброс не
случился, следующее сообщение владельца породит запись с **новым** `resetsAt`, и придёт поправка.

## Доказательство

Режим `--selftest` кладёт синтетическую запись в `/tmp` и гоняет **тот же** путь разбора, не
касаясь живого журнала сессии:

```
контроль: синтетическая запись положена, сброс через 45 с
ЛИМИТ: пятичасовое окно, сброс 05.09 09:30
будильник заведён: через 70 с
отправлено -> 90413601          ← первая телеграмма
объявляю сброс
отправлено -> 90413601          ← вторая телеграмма
```

Живая установка: `fractera-limit-watch` online, `restarts=0`, `pm2 save` выполнен, автозапуск был
включён ранее. Канал не тронут: опрашиватель по-прежнему **ровно один**, `claude` тот же процесс с
непрерывным uptime 7 ч.

## Что названо, а не забыто

- `"overageDisabledReason":"out_of_credits"` — переход на платный перерасход выключен **только
  потому, что на счету нет кредитов**. С кредитами бот при исчерпании лимита не замолчал бы вовсе,
  а продолжил бы работать за деньги. Это другой продукт, не замена сторожу: сторож нужен и с
  кредитами — владелец захочет знать, что перешёл на платное.
- Процессов pm2 теперь **десять**. Прежний счёт «девять» в шаге 115 🪦 устарел.
