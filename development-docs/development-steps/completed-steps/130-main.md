# Шаг 130 — haiku по умолчанию и двуязычие фиксированных текстов

## 1. Модель `haiku` на старте — всегда

**Заказ владельца:** «сделай по умолчанию мне модель haiku, чтобы на старте все стартовали с этой
модели».

🔒 **УМОЛЧАНИЕ ЖИВЁТ В ПУСКОВОМ ФАЙЛЕ, А НЕ В ФАЙЛЕ НАСТРОЙКИ.** Файл `/opt/fractera/agent-model`
можно удалить, перезаписать или потерять при переносе; умолчание, живущее только в нём, — это
умолчание, которое однажды молча исчезнет. `DEFAULT_MODEL=haiku` в `claude-channel.sh` переживает
всё, кроме правки самой строки.

✅ **Доказано негативным контролем — файл настройки УДАЛЁН, и канал всё равно поднялся на haiku:**

```
rm -f /opt/fractera/agent-model  →  claude … --model haiku
```

Таблица логики (проверена прогоном):

| в файле | итог |
|---|---|
| пусто / файла нет | `--model haiku` |
| `haiku` | `--model haiku` |
| `opus` | `--model opus` |
| `opus; rm -rf /` | **отвергнуто**, `--model haiku` |

## 2. Ответ на вопрос владельца: тексты ГОТОВЫЕ, а не порождённые

**Он спросил:** «фиксированные тексты, которые ты мне отправляешь, они генерируются или лежат
готовые?»

**Лежат готовые, в коде.** Их четыре у сторожа и два у сброса:

| Текст | Где живёт |
|---|---|
| «⛔ Лимит подписки исчерпан…» | `channel-watch.js` |
| «✅ Лимиты сброшены…» | `channel-watch.js` |
| «♻️ Бот перестал читать сообщения…» | `channel-watch.js` |
| «🔴 …перезапустить канал не получилось» | `channel-watch.js` |
| «♻️ Контекст сброшен…» | `agent-reset.sh` |
| описания команд меню | `agent-commands.sh` |

🔒 **И ИНАЧЕ БЫТЬ НЕ МОЖЕТ, ЭТО НЕ ЛЕНЬ.** Сторож обязан сказать про исчерпанный лимит именно
тогда, когда модель НЕ отвечает. Текст, который надо у кого-то попросить, в этот момент попросить
не у кого.

**Всё остальное, что приходит в Telegram, порождает агент** — там язык и тон его.

## 3. Двуязычие — ru + en

**Слово владельца:** «сейчас достаточно русский английский».

```
язык:      файл /opt/fractera/agent-lang  (ru | en), умолчание ru
словарь:   WORDS в channel-watch.js — 15 ключей, оба языка симметричны
проверка:  ключей совпало 15 · расхождений 0
```

🔒 **ЯЗЫК — НАСТРОЙКА, А НЕ УГАДЫВАНИЕ.** `language_code` собеседника Telegram отдаёт только
ВМЕСТЕ с сообщением, а сторож пишет САМ, без входящего письма. Значит язык взять неоткуда, кроме
файла.
🔒 **СЛОВАРЬ ЧИТАЕТСЯ НА КАЖДОМ СООБЩЕНИИ** — правка файла применяется сразу, без перезапуска.

### Меню бота — исключение, и там язык выбирает Telegram

У `setMyCommands` есть `language_code`, и списка два: русский ставится БЕЗ него (как список по
умолчанию), английский — с `language_code: en`. **Telegram сам отдаёт клиенту тот, что подходит.**

🛑 **УМОЛЧАНИЕ — РУССКИЙ, А НЕ АНГЛИЙСКИЙ:** владелец русскоязычный, и телефон с неведомой локалью
должен показать ему понятное, а не «Welcome and how to pair».

✅ **Проверено в обеих областях и на обоих языках:**
```
язык по умолчанию: 6 команд · «Сколько токенов израсходовано в этой сессии»
язык en:           6 команд · «Tokens spent in this session»
```

файле настоящий перевод строки внутри `tr -d '…'`. Поймано чтением `cat -A` и исправлено
инструментом точечной правки — тем самым, который я себе прописал уроком в шаге 119.
🔒 **Правило подтверждено третьим случаем: код с кавычками и escape-последовательностями
генерировать скриптом нельзя — только точечная правка.**
