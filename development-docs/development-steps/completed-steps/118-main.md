# Шаг 118 — бот замолчал на два часа: модальный вопрос, который некому нажать

**Симптом владельца, дословно:** «Привет, ты всё ещё на связи?.. В чём дело? Ты уснул?» — два
сообщения без ответа. Его вопрос: это сбой или нужно переподключаться?

**Ни то, ни другое.** Сессия стояла на блокирующем вопросе о правах с **09:29**.

## Что случилось

Владелец отправил боту **голосовое сообщение**. Плагин каналов сохранил его в свой склад
`/root/.claude/channels/telegram/inbox/1788593385604-…oga` — то есть **вне рабочей папки**
`/opt/fractera/agent-workspace`. На чтение файла Claude Code показал модальное окно:

```
Read(/root/.claude/channels/telegram/inbox/1788593385604-AgADAiAAAtV72VA.oga)
Allow reads outside the working directories?
  1. Yes, keep allowing …   2. No, block …   3. Ask again next time
```

Нажать клавишу **некому**: интерфейс живёт под `pm2` без терминала. Сообщения продолжали приходить —
они видны на том же экране под вопросом, непрочитанными.

## ✗ Чем оплачен закон, записанный шагом 115

Шаг 115 гласил: плагин объявляет `claude/channel/permission`, значит запрос разрешения уезжает
владельцу в Telegram, и опасный флаг не нужен. **Утверждение верное и недостаточное.**

🛑 **ПЕРЕСЫЛАЮТСЯ РАЗРЕШЕНИЯ ИНСТРУМЕНТОВ, А ВОПРОС О ПОЛИТИКЕ ПУТЕЙ — НЕ ИНСТРУМЕНТ.** Он приходит
от самого CLI, до всякого инструмента, и плагин про него не знает.

🔒 **ЗАКОН ШИРЕ ОДНОГО СЛУЧАЯ: У ПОЛНОЭКРАННОГО АГЕНТА ПОД `pm2` ЛЮБОЙ МОДАЛЬНЫЙ ВОПРОС РАВЕН
ЗАВИСАНИЮ.** Правильный вопрос при заведении такой связки — не «пересылаются ли разрешения», а
**«есть ли на этом пути вопрос, который НЕ пересылается»**.

## 🛑 Почему все приборы показывали «работает»

```
pm2 list                      → online, restarts=0, uptime растёт
pgrep bun run --cwd           → 1 (ровно один опрашиватель)
ss | grep 149.154             → 1 (живое соединение с датацентром Telegram)
отказов по квоте в журналах   → 1, и та от 00:32 — сегодняшнего лимита НЕ было
сторож лимита                 → жив, молчит правильно
```

**Все пять зелёные, и бот при этом молчал два часа.** Правду сказал только ANSI-лог, очищенный от
управляющих последовательностей. 🔒 **Диагностика этого класса — по ПОСЛЕДНЕМУ ЭКРАНУ, а не по
списку процессов.**

✅ **Сторож лимита (115-3) отработал верно, и это тоже проверка:** он не прислал ложной тревоги,
потому что лимита не было. Молчание сторожа оказалось правдивым.

## Лечение

В `/opt/fractera/claude-channel.sh` добавлен **один флаг**:

```
claude --channels plugin:telegram@claude-plugins-official --add-dir /root/.claude/channels/telegram
```

🔒 **НАЗВАНА ПАПКА, А НЕ СНЯТА ПРОВЕРКА.** Открыта ровно одна директория — та, куда плагин кладёт
присланные человеком файлы. Убрать `blockReadsOutsideWorkingDirectories` из настроек значило бы
открыть агенту весь диск ради одной папки. Почта бота лежит там же, где бот её получает; это
признание факта, а не расширение прав.

## Доказательства

```
sha пускового файла: 86a0cea307dd8b6d · bash -n → SYNTAX_OK · копия прежнего в /root/revision-117-backup/
цепочка: bun ← claude(--add-dir) ← script ← PM2 God
опрашивателей: 1 · соединений с Telegram DC: 1 · pm2 save выполнен
```

**Негативный контроль на очищенном логе, по границе перезапуска:**

| Поиск «reads outside the working directories» | Вхождений |
|---|---|
| ПОСЛЕ баннера новой сессии | **0** |
| ДО него (застрявшая сессия) | **1** |

Второе число доказывает, что поиск рабочий: он находит вопрос там, где тот был.

✗ **Первый замер этого контроля был снят неверно** — я искал строку по всему хвосту лога, а лог
дописывается, и текст мёртвой сессии в нём остаётся навсегда. Получилось «1» там, где ответ должен
быть «0». 🔒 **Лог append-only: «в файле есть» и «на экране сейчас» — разные утверждения**, и второе
измеряется только по границе последнего баннера.

## 🛑 Цена, названная владельцу

- **Контекст прежней сессии потерян** — перезапуск был единственным способом снять модальное окно.
- **Голосовое сообщение 09:29 не обработано.** Файл цел на диске; само обновление Telegram уже
  вычитано плагином и повторно не придёт. Владельцу проще сказать это ещё раз.
- **Проверка лечения — за владельцем:** одно голосовое боту. Текст пройдёт и без флага; сломалось
  именно на голосовом.
