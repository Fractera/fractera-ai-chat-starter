## Что построено

`http://213.199.61.7:3600/terminal` — настоящая оболочка боевого сервера в браузере, с одной
кнопкой «Вход по подписке Claude Code». **Подписка подключена владельцем:** `claude auth status` →
`loggedIn: true`, `authMethod: claude.ai`; TUI показывает «Sonnet 5 · Claude Pro».

Мост живёт в процессе чата на том же порту — решение владельца. Отсюда ноль правок вне репозитория
чата: nginx уже несёт `Upgrade` на `location /` блока `chat.<домен>`, а `bootstrap.sh` запускает
`pm2 start pnpm -- start`, то есть читает наш же `start`.

## Замок, которого у оригинала не было

Мост до шага 500 принимал ЛЮБОЕ соединение — ни токена, ни куки, ни проверки origin. Здесь дверь
`POST /api/fractera/pty-ticket` проверяет сессию и роль архитектора и выдаёт одноразовый билет на
60 с; мост гасит билет ДО любой другой проверки. Доказано прибором из шести случаев, **три из них
негативные**: замок, не показанный закрытым, не проверен.

🔒 **Билет живёт в `.mjs`, а не в `.ts`, и это главное решение шага.** Файл читают две половины —
дверь внутри сборки Next и `server.mjs` рядом; вторая реализация стала бы второй правдой об одном
замке. Хранилище на `globalThis`: процесс один, а экземпляра модуля два.

## Шесть дефектов, и пять из них выглядели как успех

1. **Регулярка распознавания ссылки совпала по домену и разошлась по границе конца.** Модалка
   открылась бы с испорченной ссылкой — отказ, указывающий не туда. Чтением не ловится.
2. **`node-pty` под linux не имеет готовой сборки**, а pnpm 10 не запускает скрипты сборки по
   умолчанию: модуль встал бы «успешно» и не загрузился.
3. **Замок под `cacheComponents` блокировал рендер всей страницы.** Нашла только консоль браузера:
   типы, линтер и прибор были зелёными.
4. **Свой сервер поднимал Next в режиме РАЗРАБОТКИ на боевой машине.** `BUILD_RC=0`, служба
   поднялась, страницы `200`, консоль чиста — а боевая сборка лежала неиспользованной. Нашлось по
   **списку сетевых запросов**: там был `hmr-client`.
5. **Состояние терминала переезжало между сессиями.** TUI включает слежение за мышью и не выключает
   при обрыве; движение по тачпаду печатало мусор, а тот же мусор портил код входа. Обе жалобы
   владельца — одна причина.
6. **Проверка входа однострочником была видна человеку** — стена shell вместо приветствия.

🔒 **ЗАКОН ШАГА, ГОДНЫЙ ШИРЕ ЕГО: У СТРАНИЦЫ ЧЕТЫРЕ ПЛОСКОСТИ ДОКАЗАТЕЛЬСТВА, А НЕ ТРИ.** Типы ·
сборка · консоль браузера · **список сетевых запросов**. Консоль показывает, что сломалось; список
показывает, **что за код вообще приехал**. Когда разметка верна, а поведения нет, вопрос второй.

## Чего в шаге нет

- **Гермес.** Отложен решением владельца: рантайма у нас нет ни в одном репозитории, он ставился
  блоком в закрытом `bootstrap.sh`, а происхождение названо одной строкой в `.gitignore`.
- **Передача данных через терминал** — «предмет отдельного разговора» словом владельца.
- **Прогон `bootstrap.sh`** — он исполняется только при рождении сервера.

## Решение владельца о защите, дословно
